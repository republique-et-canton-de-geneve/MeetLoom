# SessionLab parity — MeetLoom acceptance criteria

Audit dated September 23, 2026, based on official SessionLab documentation and MeetLoom source code at that date. **Full functional equivalence has not been validated.** This matrix defines the product target and supersedes the earlier arbitrary “after V1” deferrals in `product-research.md` and `implementation-plan.md`. The acceptance target is explicit: SessionLab functionality with an original visual identity and useful ergonomics from SessionLab and SessionPlan. A non-excluded feature remains required even when implementation is sequenced after another feature.

The only accepted functional exclusions are Parking lot, the block/session library and block attachments. Features directly dependent on these exclusions are identified below. Free use, internal hosting, internal Qwen, column audiences, early sound alerts and the floating window are requested adaptations. SessionLab pricing tiers, commercial limits and billing do not need to be reproduced in a free application; their premium functionality remains in this checklist.

“Present” means found in the implementation, **not fully validated through comparative UI and user-workflow testing**. “Partial” means the same outcome or workflow is not yet achieved. Every acceptance checkbox stays open until its scenario has been run in both applications. This audit covers documented families in [Planner][planner-collection], [Collaboration][collaboration-collection], [Multi-day][multiday-collection], [Exports][exports-collection], [Workspaces][workspace-collection] and [Account][account-collection], not undocumented private functionality. The signed-in UI must resolve the documentation differences listed at the end.

## Common fixture and visual identity

Manually create an original session in both applications named **“Atelier de décision” (Decision workshop)**, description “Préparer trois décisions pour l'équipe,” client “Équipe pilote,” tags “décision” and “interne,” timezone Europe/Zurich. Day 1: October 12, 2026, 09:00; Welcome (“Accueil”) 10 min, Analysis (“Analyse”) 20 min, Break (“Pause”) 10 min, Decision (“Décision”) 20 min. Day 2: October 13, 09:00; Review (“Retour”) 10 min, Workshop (“Atelier”) 30 min, Closing (“Conclusion”) 10 min. Add the variants required by each row. Use two accounts, owner A and collaborator B, and anonymous browser V. French strings preserve the original QA fixture; instructions and UI names below use English.

For each workflow, record a SessionLab screenshot, a MeetLoom screenshot, the result and any functional difference. Use the same viewport and zoom: 100%, desktop 1440 × 900, then mobile 390 × 844. Compare command access, useful density, hover states, focus, menus, scrolling and overlays. **Do not copy SessionLab's design, colors, typography or dimensions**: the user explicitly requested an original identity. Action count, editing speed and continuity of context should guide ergonomic comparison.
